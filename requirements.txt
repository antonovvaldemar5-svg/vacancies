# Парсер вакансий с HH.ru

Курсовой проект по работе с API.

## Функционал
- Поиск вакансий на HH.ru
- Сохранение в JSON
- Фильтрация по зарплате
- Поиск по ключевым словам
- Консольный интерфейс
