# Курсовая работа: Интеграция с API HH.ru

## 📋 Описание
Программа для поиска и сохранения вакансий с сайта hh.ru. Позволяет:
- Искать вакансии по ключевым словам
- Сохранять вакансии в JSON файл
- Фильтровать по зарплате и ключевым словам
- Сортировать по зарплате
- Выводить топ N вакансий

## 🚀 Установка

### Требования
- Python 3.10+
- Poetry или pip
